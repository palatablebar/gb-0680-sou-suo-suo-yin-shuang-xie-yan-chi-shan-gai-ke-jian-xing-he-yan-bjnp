# 双写定义

event_id唯一，doc_id文本保留。side为source或index；版本正整数按Decimal比较并作为文本序列化。upsert要求JSON对象，delete忽略payload并产生墓碑。相同文档同端同版本不同内容全部隔离，存在未裁决冲突的主体不回落旧版本；同内容合并来源；较高版本覆盖低版本，迟到旧写不得覆盖墓碑。墓碑同时携带撤下前最后一份可见正文（同端版本低于墓碑的最高upsert，含版本与来源行），无该upsert时正文不可还原。

撤下裁决只看墓碑不够：墓碑仅证明存在删除事件，证明不了两端撤下的是同一份正文。每篇撤下文档产出唯一撤下结论号TD-*（按doc_id、墓碑版本确定性派生），结论三态：两端撤下前正文都可还原且一致为撤下完成；可还原但内容不同为撤下正文不一致；任一缺墓碑或缺撤下前正文为撤下待证。后两态不得签收关单，门禁reported=0，无法还原时禁止冒充撤下完成。非撤下文档结论为非撤下、无结论号。核验页面与导出凭据共用同一行内结论号与结论，导出CSV含takedown_id、takedown_state列；结论号重复时拒绝归档。结论由输入内容派生，同源重跑只复用已有批次，结论保持一致且不新增记录。

双端最终版本、操作、文档分别核验。目标缺失、删除未确认、索引领先、陈旧索引、内容差异分开展示。source_time与visible_time带偏移；可见延迟按实际秒数。默认阈值120秒，等于阈值通过。已可见但超过阈值为延迟，尚无目标且等待时间超过阈值为缺失，等待中不冒充延迟。

对账expected=每文档应通过的1，reported=门禁通过1或未通过0，逐条保存visibility_state和gate原因，允许按文档复核。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
